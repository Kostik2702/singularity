## 3. Эталонные артефакты для побайтового сравнения

Сохранены вне репозитория (не коммитятся — содержат путь к личному vault):

| Файл | SHA-256 |
|---|---|
| `baseline-curator.json` | `22444048828409957ACE7B66AA983E76794E8CAF9A51C7FDB20D3F077BEC9345` |
| `baseline-digest.json` | `2E8E3BFA81E3AF73C34A7328B2CE7058404A0E257A3CE886315B1C0C498173FF` |

⚠️ **Важно про сравнение.** Эти хеши валидны только при неизменном содержимом
vault. Vault живой: любая новая заметка (включая 7 заметок `decisions/WIKI-LOOP
D1…D7`, добавленных в W00) меняет вывод `curator`/`digest` законно.

Поэтому главный гейт W03 формулируется **относительно**, а не абсолютно:
> снять `curator --json` и `digest plan --json` НЕПОСРЕДСТВЕННО перед
> наполнением `.mb/sources/`, затем повторить сразу после — вывод обязан быть
> побайтово идентичен.

Абсолютные хеши выше нужны для другого: доказать, что рефактор `similarity.py`
(W05) и миграция конфига (W10) не изменили вывод при неизменном vault —
там сравнение делается в пределах одного прогона (до/после в одной сессии).
