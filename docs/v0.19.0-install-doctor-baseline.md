## 6. How to catch a regression

- `K2-code-graph` naming a finding beyond the 8 accepted ones — a real
  secret-shaped value reached a graph.
- `D10-rules-inventory` above 64.
- Any `pass: false` in `v0110_package_layout`, in particular the
  `extract_java` or `extract_kotlin` import: a wheel or an environment
  without the grammars.
- A console window flashing after a boot: a new subprocess call without
  `platform.proc.NO_WINDOW` that the guard did not see (it scans only the
  package, and only `subprocess.*` and `os.system/popen`).
- A red CI job on any OS. The matrix runs on every push of a release branch;
  this release's first run is why a plant must be observable on all three.
