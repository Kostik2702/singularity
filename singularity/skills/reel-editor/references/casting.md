# Кастинг-лист: кто допущен и где он в сюжете

Единственный артефакт конвейера, который держит **смысл**, а не измерение.
Поэтому его заполняет человек или скил, а движок только проверяет.

## Зачем он есть

Два провала, невидимых для всех остальных проверок, потому что склейка на бите,
ось цела, цвет сведён:

**Причинность.** Мир «раз-случается». Земля трескается → рука пробивает землю →
снова целая трещина. Замерено на живой сборке: ни одна проверка не сработала.

**Мёртвый груз.** В любой генеративной пачке есть дубли, которые нельзя брать —
не тот персонаж, поломанная анатомия, артефакт через кадр. Без места, где
записано «отклонён, потому что…», это переобсуждается при каждом касании EDL.

## Как заполнять

```bash
reel cast new "<папка>" --out cast.json     # скелет: все клипы, verdict '?'
reel cast show cast.json                    # что ещё не отсуждено
```

Заполнять **во время чтения плотных контактных листов**, одним проходом, до
выбора первой in-точки. Заполнение после сборки — это придумывание оправданий
уже сделанным склейкам.

| Поле | Что писать |
|---|---|
| `verdict` | `use` · `partial` · `reject` · `?` |
| `note` | при `reject` — обязательно причина, человеческим языком |
| `depicts` | id кадра раскадровки, который клип закрывает |
| `stage` | положение в СЮЖЕТЕ (см. ниже) |
| `usable` | `[от, до]` в секундах — годный кусок клипа |

## Как размечать `stage`

Стадия — это **состояние мира**, а не номер кадра и не место на таймлайне.
Вопрос, на который отвечает число: *что уже произошло к этому моменту и не может
развидеться?*

Пример разметки, снятый с реальной работы:

| stage | состояние мира |
|---|---|
| 1 | могила цела, ничего не началось |
| 2 | земля трескается, свет из-под земли |
| 3 | рука пробила землю |
| 4 | фигура выбралась и стоит |
| 5 | идёт по городу |
| 6 | город горит, толпа поднялась |
| 7 | старый мир пал |

Правила разметки:

- **Стадии не про «интереснее/сильнее», а про необратимость.** Если два кадра
  можно поменять местами без вранья — у них одна стадия, и это нормально.
- **Общие и детальные планы одного события — одна стадия.** Крупный план короны
  и общий план того же зала не сдвигают мир.
- **Не выдумывать глубину.** Пять стадий на клип честнее двадцати, из которых
  половина неотличима.
- **Романтическая линия — тот же механизм** (взгляд → прикосновение → объятие →
  поцелуй), поле `heat`. Это стадии, названные по-другому.

## Что делает движок

`reel validate <edl> --cast cast.json`:

- отказывает, если план взят из `reject`-клипа — и печатает записанную причину;
- отказывает, если клип ещё `?`;
- подставляет `stage` из листа в планы, где он не проставлен руками;
- при `partial` проверяет, что план читает только годный интервал;
- ловит любой откат стадии ниже уже достигнутого максимума.

Проверка идёт по **бегущему максимуму**, а не по предыдущему плану: иначе один
провал спрячет всё, что за ним.

## Единственный законный откат

`reprise: true` на плане. Это осознанная реприза или флешбэк: повтор кадра через
две минуты — рекапитуляция, а не заедание. Флаг ставится **в момент решения**;
поставленный задним числом, чтобы «прошло», он превращает проверку в формальность.
