# Пресеты: текст и свет

Оба регистра — работающие конфигурации, снятые с готовых роликов, а не примеры.
Метод один; грамматика противоположная. Смена жанра меняет ВСЁ сразу, а не только шрифт.

## Текст

| | `club` | `editorial` |
|---|---|---|
| темп | 126 BPM | 105.5 BPM |
| гарнитура | Bebas Neue (конденс-гротеск) | Cormorant Garamond (засечная) |
| вес | обычный | roman 600 / italic 500 |
| регистр | ALL CAPS | предложениями |
| трекинг | 6 px | 2 px |
| строка 1 | белый `#FFFFFF` | кремовый `#FAF5EE` |
| строка 2 | магента `#FF2E88` | шампань `#E2BA82`, **курсив** |
| обводка | 3 px чёрная | нет |
| тень | alpha 210, blur 9 | alpha 185, blur 12 |
| свечение | bloom на строке 2 | нет |
| скрим | 155 | нет (текст в свободной полосе) |
| вход | сборка из окружающего света | наводка на резкость |
| длительность входа | 7 кадров на глиф, стаггер 0.34 | 14 кадров на строку |
| задержка строки 2 | 5 кадров | 7 кадров |

| ширина строки | 912 px | 900 px |

### Почему именно так

- **Обводка снимается вместе со сменой на засечную.** Жёсткий контур утолщает волосяные штрихи и убивает рисунок. Контраст тогда обеспечивается положением: текст лежит в тёмной размытой полосе под кадром.
- **Свечение своего тона — не средство читаемости.** Замер: магента на белой футболке дала 1.82:1 при формально «оформленном» тексте. Разделение даёт контур глифа, а не bloom.
- **Kicker-штрих удаляется, если попал не туда**, а не двигается: пара «прямой + курсив» стиль уже несёт.
- **Кегль всегда один** на весь ролик, по самой длинной строке. Построчная подгонка ломает систему и читается как ошибка.

## Свет

Арка по актам, не равномерный строб. Амплитуда тратится там, где больше запас по частоте.

| акт | доля ролика | на доле | на такте |
|---|---|---|---|
| I установка | 0–28% | — | 0.16 |
| II развитие | 28–55% | 0.08 | 0.20 |
| III пик | 55–85% | 0.12 | **0.36** |
| IV спад | 85–100% | — | 0.22 → 0, с затуханием |

- цвета чередуются по тактам: магента / циан;
- на тактовых ударах подмешано 35% белого — головка прибора, а не цветной гель;
- градиент ярче сверху (`grad_floor=0.25`): свет падает со сцены, а не заливает кадр плоско;
- спад `exp(-frac*9)` ≈ 2–3 кадра;
- вспышка ложится **под графику**, иначе измеренный контраст текста перестаёт действовать.

### Частоты и потолок

При 126 BPM: доля = 2.1 вспышки/с, такт = 0.53/с, подделение = 4.2/с.
Порог WCAG 2.3.1 — **3 в секунду**. Подделения запрещены структурно: `LightRig.verify_cadence()`
отказывает конфигурации, которая его перешла бы.
