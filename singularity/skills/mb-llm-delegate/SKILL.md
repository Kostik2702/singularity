# mb-llm-delegate — оркестратор ↔ локальный исполнитель

Локальная модель (`mb llm start <model>`, endpoint `127.0.0.1:PORT/v1/messages`,
Anthropic-совместимый) — **исполнитель**. Ты — **оркестратор/контролёр**.

## Почему так, а не полноценный Claude Code на локалке

Мелкая модель заваливает агентную петлю: путает/зацикливает вызовы тулов
(наблюдалось `TaskOutput(mb-search)` в бесконечном цикле). Поэтому ей шлём
**одиночные промпты БЕЗ tool-use** — генерацию она тянет, а тулы/файлы/ревью
остаются на оркестраторе. Никаких jinja-крашей и петель.

## Разделение ролей (строго)

- **Исполнитель (локалка):** пишет ВЕСЬ код — и первичный, и правки. Возвращает
  полный файл текстом.
- **Оркестратор (ты):** формулируешь задачу, передаёшь текущий файл, **записываешь
  её вывод на диск** (механическая транскрипция — у модели нет файловых тулов),
  ревьюишь результат. Нашёл баг — **не чини сам**: сформулируй правку и отдай
  обратно исполнителю, он возвращает исправленный полный файл, ты пишешь и
  проверяешь снова. Итерируй до чистого результата.

## Использование

```bash
SK="$HOME/.claude/skills/mb-llm-delegate/delegate.py"

# генерация нового файла
python "$SK" --task "Создай ..." --outfile D:/path/app.html

# правка/добавление фичи: отдать текущий файл + инструкцию, получить полный новый
python "$SK" --infile D:/path/app.html \
  --task "Добавь X. Верни ПОЛНЫЙ обновлённый HTML-файл целиком." \
  --outfile D:/path/app.html

# исправление найденного бага (ты нашёл — оно чинит)
python "$SK" --infile D:/path/app.html \
  --task "Баг: <описание>. Почини и верни ПОЛНЫЙ файл." \
  --outfile D:/path/app.html
```

Флаги: `--system` (своя системка; дефолт — «output ONLY complete file, no fences»),
`--max-tokens` (дефолт 6000; при `stop=max_tokens` подними), `--print` (эхо в stdout),
без `--outfile` вывод идёт в stdout.

## Контроль качества (обязателен на каждой итерации)

- [ ] Прочитай записанный файл, не доверяй на слово.
- [ ] Синтаксис: `node --check` для JS, компилятор/линтер для своего языка.
- [ ] Логика/ресурсы: утечки (создание DOM/подписок в цикле), off-by-one,
      обрезка по `max_tokens`, «выехавшие» трансформы и т.п.
- [ ] Баг → инструкция исполнителю (см. пример выше), НЕ правка руками.

## Требования

- Модель поднята: `mb llm status --json` → `server_alive: true`. endpoint/порт/модель
  скрипт берёт оттуда сам (fallback `127.0.0.1:8080`).
- Проси модель **всегда возвращать файл целиком** (не диффом) — так запись атомарна
  и не надо мержить.
