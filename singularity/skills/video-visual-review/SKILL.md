# video-visual-review — приёмка видео-контента

Детерминированная часть — `scripts/video-report.py` (envelope `video-review/1`, exit 0/2) поверх ffprobe и `imgqa sheet` (schema_version 2 пинится). Скил интерпретирует evidence; **контентные решения не принимает**.

> **Правило нулевого кода:** «прочитать метаданные / нарезать кадры / склеить sheet» — это уже `video-report.py` и `imgqa sheet`. 0 новых скриптов за сессию.

## Порядок

```bash
# Полный отчёт: метаданные + contact sheets (идемпотентно, атомарно)
E:\Singularity\.venv\Scripts\python.exe \
  "E:\Singularity\singularity\skills\video-visual-review\scripts\video-report.py" \
  --input "<папка или файл>" --out "<evidence-dir ВНЕ проекта>" --json
# IMGQA_PROTECTED_ROOTS=<project> запрещает запись в проект физически.
# Большие HEVC (до 375MB NIKA-мастеров) работают; таймаут sheet 600с/файл.
```

Выходы: `report.json` (typed, rerun байт-стабилен), `report.txt` (формат эталона NIKA `reports/video-review/ffprobe-report.txt` — прямой diff), `<stem>.sheet.<ext>.jpg` per файл.

## Методика интерпретации (по evidence, не по памяти)

1. **Прочитать contact sheets мультимодально** (Read). Смотреть: занимает ли субъект всю ширину кадра в ключевых фазах движения; есть ли вертикальная «сердцевина», которую можно кропнуть без потери субъекта.
2. **Рекомендация crop vs blurred-letterbox:**
   - Кроп в вертикаль допустим ТОЛЬКО если субъект во всех фазах остаётся в центральной трети (проверить по sheet-кадрам, указать номера кадров как evidence).
   - Прецедент NIKA-03: танцоры при поворотах занимали всю ширину 1920×1080 → вертикальный кроп отрезал бы партнёра → **blurred-letterbox**. Это дефолт для динамики во всю ширину.
3. **`rotation` в report.json** ≠ 0 — кадр хранится повёрнутым; реальная ориентация = после поворота, учесть до вердикта о пропорциях.
4. **Структура контента** (одна съёмка или разные работы, merge, титры, порядок) — вопросы владельцу с evidence, НЕ решения. Урок NIKA-03: визуальный просмотр полностью перевернул предполагаемую структуру — 5 «независимых работ» оказались одной съёмкой; merge решал владелец.
5. Вердикт и вопросы владельцу — в learnings задачи (`mb learn`), sheets — как evidence-ссылки.

## Web-энкод (опционально, параметры NIKA-03)

```bash
ffmpeg -i IN.MOV -c:v libx264 -crf 23 -vf "scale=-2:720" -movflags +faststart -c:a aac -b:a 128k OUT.mp4
# постер: кадр из sheet-фазы, jpeg q~80, бюджет ≤120KB
```
Энкод — только после контентных решений владельца.
