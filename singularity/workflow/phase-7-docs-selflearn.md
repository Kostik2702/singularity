# Phase 7 — Docs + Self-learn (финал задачи)

Родитель: `_router.md`.

- [ ] Learnings-финализация: один вопрос пользователю «финализировать learnings?» → плотный итог задачи в learnings-док (skill `mb-memory`: только неочевидное, код как file:line, решения с owner).
- [ ] Строка в `changelog/YYYY-MM.md` (единственная история памяти).
- [ ] **Self-learn:** были ошибки/грабли в ходе задачи? → правило в точку исполнения (конкретный skill / rule-заметка / CLAUDE.md), GATE «поймало бы ИМЕННО этот сбой?», метка LEARNED. Пример-образец: [[Rule - stdin хуков читать utf-8-sig]].
- [ ] Задача закрыта → learnings-док со временем в `learnings/archive/` (когда точно не вернёмся).
- [ ] Периодически (не каждую задачу): skill `memory-curator` — связи/orphans/здоровье vault.
- [ ] 📋 Финальный CHECKBOX REPORT по фазам: только фейлы/`[➖]` + строка «N/M passed».

**Выход:** знания зафиксированы, система стала умнее. Конец воркфлоу.
