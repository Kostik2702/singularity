# Phase 7 — Docs + Self-learn (the end of the task)

Parent: `_router.md`.

- [ ] Finalise the learnings: one question to the user, "finalise the learnings?" → a dense summary of the task in the learnings document (the `mb-memory` skill: only the non-obvious, code as file:line, decisions with an owner).
- [ ] A line in `changelog/YYYY-MM.md` (the memory's single history).
- [ ] **Self-learn:** were there mistakes or traps during the task? → a rule at the point of execution (a specific skill / a rule note / CLAUDE.md), the GATE "would it have caught PRECISELY this failure?", and a LEARNED mark. A model example: the vault rule about reading hook stdin as utf-8-sig.
- [ ] Task closed → in time the learnings document moves to `learnings/archive/` (once we are certain we will not come back to it).
- [ ] Periodically (not every task): the `memory-curator` skill — links, orphans, vault health.
- [ ] 📋 Final CHECKBOX REPORT across the phases: failures and `[➖]` only, plus the line "N/M passed".

**Exit:** the knowledge is recorded and the system got smarter. End of the workflow.
