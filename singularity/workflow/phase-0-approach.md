# Phase 0 — Choosing the approach

Parent: `_router.md`.

- [ ] Pick the route from the category set in `phase-SB-step-back.md`:
  - **research / unfamiliar territory** → Phase 1 Investigation (deep reading of code and memory).
  - **a known bug** → systematic debugging (hypothesis → minimal check → binary search), then Phase 3.
  - **a hard bug / strange behaviour** → Investigation with the falsification protocol (try to REFUTE every hypothesis).
  - **an architectural decision** → Phase 1.5 grill → a design note (type=decision) with the alternatives.
  - **S-size mechanics** → straight to Phase 3 (mark `[➖] phases 1-2 — trivial scope`).
- [ ] The choice of route is a task decision → record it in the learnings (who and why; the solo default: `ASSUMED route X from category+size`).

**Exit:** the route is recorded → the corresponding phase.
